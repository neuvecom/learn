## ログイン画面の表示を auth.neuve.com にする

### 実施内容
- Google のアカウント選択画面の「〜に移動」が `how-to-use-vcv-rack-ja.firebaseapp.com` と出ていたので、ログイン処理のドメイン（authDomain）を `auth.neuve.com` に変えた
- neuve.com 本体は GitHub Pages なので `/__/auth/handler` を置けない。そのため Firebase Hosting にサブドメイン `auth.neuve.com` を割り当てる方式にした

### 変更
- `public/kit/neuve-learn.js`: `authDomain` を `auth.neuve.com` に変更

### 事前に必要な設定（マージ前）
- Firebase Hosting に カスタムドメイン `auth.neuve.com` を追加し、DNS レコードを Cloud DNS に登録
- OAuth クライアントの承認済みリダイレクト URI に `https://auth.neuve.com/__/auth/handler` を追加

### 後方互換性
- ログイン済みの状態は neuve.com 側に保存されているため、authDomain の変更でログアウトはされない

## ログイン前の「完了」もブラウザに記録し、ログイン時に引き継ぐ

### 実施内容
- VCV・KORG Gadget の「完了」ボタン（`<neuve-lesson-done>`）を、未ログインでも押せるようにした
- 未ログインで押した完了はこのブラウザに保存し、ログインした時点でアカウントへまとめて引き継ぐ

### 変更
- `public/kit/neuve-learn.js`
  - ブラウザ側の保存先 `neuve-learn:done:<コース ID>`（レッスン ID の配列）と `setCompletedOrGuest` を追加
  - ログインを検知したら（どのページでも）ブラウザの記録をアカウントへ書き込み、コースの最終レッスンも更新して端末側を消す。`currentUser()` はこの引き継ぎを待ってから返す
  - `getCompleted` は未ログインならブラウザの記録を返す
  - `<neuve-lesson-done>`: 未ログインでもボタンを表示し、「ログインすると引き継げる」案内を添える。切り離し・再接続でも購読し直すようにした
  - `setCompleted` と `mirrorLocalStorage` の動作は変えていない（GitHub・Claude Code・GA4 は従来どおり）

### 検証
- Firebase エミュレーター + Playwright（KORG Gadget のビルドを使用）
  - 未ログインで 1-1・1-2 を完了 → 再読み込み後も完了表示、ブラウザに 2 件
  - ログイン → アカウントに 2 件書き込まれ、ブラウザ側は削除、案内が消える
  - 別ブラウザで同じアカウントにログイン → 1-2 が完了表示、マイページに「2 / 22 完了・次は レッスン1-3」

### 後方互換性
- 既存のアカウントの記録には影響なし。ログイン済みの動作は従来どおり
