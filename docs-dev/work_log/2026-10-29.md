## ログイン画面の表示を auth.neuve.com にする

### 実施内容
- Google のアカウント選択画面の「〜に移動」が `how-to-use-vcv-rack-ja.firebaseapp.com` と出ていたので、ログイン処理のドメイン（authDomain）を `auth.neuve.com` に変えた
- neuve.com 本体は GitHub Pages なので `/__/auth/handler` を置けない。そのため Firebase Hosting にサブドメイン `auth.neuve.com` を割り当てる方式にした

### 変更
- `public/kit/neuve-learn.js`: `authDomain` を `auth.neuve.com` に変更

### 事前に必要な設定（マージ前）
- Firebase Hosting に カスタムドメイン `auth.neuve.com` を追加し、DNS レコードを Cloud DNS に登録
- OAuth クライアントの承認済みリダイレクト URI に `https://auth.neuve.com/__/auth/handler` を追加

### 後方互換性
- ログイン済みの状態は neuve.com 側に保存されているため、authDomain の変更でログアウトはされない
